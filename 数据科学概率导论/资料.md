免费网络课程

  - Harvard Stat 110 (https://stat110.hsites.harvard.edu/)：概率直觉和解题思维很好，配 Blitzstein 与 Hwang《Introduction
    to Probability》第二版。

  - MIT 6.041SC
    (https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/)：最完整的自学课程之一，包含视频、习题、解答和考试。

  - Berkeley Data 140 (https://data140.org/textbook/)：专门面向数据科学的概率课程和免费教材。
  - Seeing Theory (https://seeing-theory.brown.edu/)：交互式概率统计可视化。
  - StatQuest (https://statquest.org/video-index/)：适合快速弄清假设检验、回归、正则化和机器学习概念。


 推荐学习路线

Chan 2026 主教材 + Stanford CS109 + 盛骤第五版查漏补缺 + ISLP Python 实践

  1. 主线阅读 Chan 第 1 至第 9 章，第 10 章随机过程可根据时间序列、信号处理或强化学习需求选学。
  2. 同时参考 Stanford CS109，重点关注算法分析、信息论、MLE、逻辑回归等计算机内容。
  3. 用盛骤第五版补齐国内课程常见的抽样分布、卡方/t/F 分布、经典参数估计和假设检验。
  4. 随后学习 ISLP Python 版，并实际完成每章 Python Lab。
  5. 最后选读 Murphy《概率机器学习》，把概率论、统计推断和现代机器学习统一起来。
