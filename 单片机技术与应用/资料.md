## 教材

### [Embedded Systems Fundamentals with Arm Cortex-M based Microcontrollers: A Practical Approach](https://www.arm.com/resources/education/books/efficient-embedded-systems-nucleo)

**Alexander G. Dean，2nd ed.，Nucleo-F091RC Edition（2021）｜主教材**

面向一至两个学期的本科嵌入式入门，前置是 C 语言、数字电路和基本模拟接口。全书用 C 贯穿 GPIO、软件并发、Cortex-M 内核与中断、模拟接口、定时器、串行通信和 DMA；只有理解 C 与机器执行关系所需的少量汇编。它把“CPU 与外设并行工作”放在主线中，最适合建立确定性采样、非阻塞程序和实时控制所需的思维。Arm 提供[免费 PDF、目录和配套材料](https://github.com/arm-education/Embedded-Systems-Fundamentals)。

书中平台是较基础的 STM32F091RC，工具链为 Keil，不能覆盖 FPU/DSP、G4 高级定时器和电机控制外设；这些由后续资料补齐。STM32F091RC 按 [ST 官方资料](https://www.st.com/en/microcontrollers-microprocessors/stm32f091rc.html)是 Cortex-M0，并非部分教材页面所写的 M0+。

### [《单片机原理及应用（第4版）》](https://www.hep.com.cn/book/show/da35c6dd-0519-4dad-8969-892119e863d9)

**张毅刚主编，第4版（2021）｜国内课程与考试辅助**

以 AT89S52/8051 为核心，覆盖片内结构、汇编指令、定时器、中断、串口、外部接口、应用系统和抗干扰设计，并配有 Proteus 案例及同作者 MOOC。难度不高，适合按本校 syllabus 补齐传统术语、寻址/指令和接口题型。其 8 位架构、汇编和片外扩展内容不应成为工程主线；只精读任课教师和考试明确要求的部分，再把同一功能用现代 Cortex-M 实现一次。

### [Mastering STM32 – Second Edition](https://leanpub.com/mastering-stm32-2nd)

**Carmine Noviello，Second Edition｜工程应用辅助**

篇幅大、信息密度高，适合学完主教材后按专题查阅，不宜从第一页顺读。它围绕 STM32CubeIDE、CubeMX 和 CubeHAL，覆盖调试、启动与链接、时钟、NVIC、DMA、ADC/DAC、通信、FreeRTOS、自制板，以及编码器、Hall、三相 PWM 和 Break 等控制相关定时器功能。其作用是把主教材的寄存器与并发原理迁移到当前 STM32 工程工作流，重点查“定时器触发 ADC—DMA—算法—PWM/保护”这条链。

### [The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors](https://shop.elsevier.com/books/the-definitive-guide-to-arm-cortex-m3-and-cortex-m4-processors/yiu/978-0-12-408082-9)

**Joseph Yiu，3rd ed.（2013）｜进阶架构参考**

需要已经做过中断、DMA 和较完整的外设项目。按需查阅 NVIC、异常入口与延迟、Fault、内存模型与屏障、MPU、FPU、调试追踪、OS 上下文切换和 CMSIS；它能把“会调用 HAL”提升到能分析实时性和并发故障。此书不是 STM32 外设手册，具体寄存器仍以所用芯片的 Reference Manual 为准，也不必为当前课程通读。

## 免费网络课程

- [Modern Embedded Systems Programming Video Course](https://www.state-machine.com/video-course/)（Quantum Leaps，Miro Samek）：最适合配主教材。官方页面汇总 56 节视频、逐课工程和文本，从 C、机器执行、启动代码和寄存器逐步进入中断、事件驱动、状态机、测试、调度器与 Zephyr；TM4C123 和部分 STM32C031 工程要求对应开发板，但原理可迁移到 STM32G4。
- [Embedded Systems - Shape The World: Microcontroller Input/Output](https://www.edx.org/learn/embedded-systems/the-university-of-texas-at-austin-embedded-systems-shape-the-world-microcontroller-input-output)（UT Austin）：8 周实验课，先仿真再上 TM4C123，覆盖 C、GPIO、模块化、软件仪器、有限状态机和交通灯/起搏器等 8 个实验。适合需要更慢、更强引导的入门阶段；若主线用 STM32G4，不必另买 TM4C123。
- [单片机原理及应用](https://www.icourse163.org/course/HIT-353001)（哈尔滨工业大学）：完整讲授 AT89S51 的结构、汇编、中断、定时器和串口，与张毅刚教材配套。只用于国内课内与考试查漏，不替代 Cortex-M 主线。
- [STM32 MOOCs](https://www.st.com/content/st_com/en/support/learning/stm32-education/stm32-moocs.html)（STMicroelectronics）：免费专题课程库，含 STM32CubeIDE/CubeMX/HAL、FreeRTOS 和五部分 Motor Control。完成基础外设后按需选课；Cube 工具课用于工程化，RTOS 与电机控制课留到相应阶段。
- [ECE 4760/5730: Designing with Microcontrollers](https://ece4760.github.io/)（Cornell University）：进阶项目课，当前使用 RP2350/Pico 2，公开 2025 讲座、实验、代码与大量结课项目。课程把微分方程、模拟电路、DSP、控制和机电系统落到真实硬件，尤其值得参考 PID、反作用轮倒立摆、DMA、固定点和电机项目；不适合作为第一门 MCU 课。

## 实践与仿真

- **主实验平台：**新购优先 [NUCLEO-G474RE](https://www.st.com/en/evaluation-tools/nucleo-g474re.html)，配板载 ST-LINK 和官方 [STM32CubeG4 示例](https://github.com/STMicroelectronics/STM32CubeG4/tree/master/Projects/NUCLEO-G474RE)。G474 的 Cortex-M4F/DSP、ADC、比较器/运放、高级定时器、FMAC/CORDIC 与数字电源和电机控制衔接较好；入门期只用 GPIO、UART、通用定时器、ADC 和 DMA，不从 HRTIM/FOC 开始。Dean 教材的 F091 工程不能原样复制；若只想逐行复现实验可改用 NUCLEO-F091RC，但不要两块都买。
- **开发与调试：**以 [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) + [CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html) 为长期环境。先用 HAL 跑通，再对照 Reference Manual 理清时钟、NVIC、ADC 触发和 DMA；对时序敏感的关键路径再用 LL/寄存器。必须练断点、watch、寄存器和 Fault 调用栈；闭环调参后可用 [STM32CubeMonitor](https://www.st.com/en/development-tools/stm32cubemonitor.html)观察设定值、反馈、误差和占空比。
- **测量工具：**万用表、带限流的低压电源、双通道以上示波器，以及 8 通道 USB 逻辑分析仪配 [PulseView](https://sigrok.org/wiki/PulseView)。用逻辑分析仪核验 UART/SPI/I²C、PWM 和中断时序，用示波器观察模拟输入、PWM 边沿、纹波和故障关断。功率实验先低压限流；普通示波器地夹通常接保护地，不能随意夹到半桥高侧。
- **仿真取舍：**[Wokwi STM32](https://docs.wokwi.com/guides/stm32)仅用于无板时的 GPIO、UART、简单总线和状态机烟雾测试，其 STM32 模型与 DMA/模拟外设不完整，不能验证 G4 的 ADC-DMA-PWM 同步或电机闭环。Proteus 仅在学校已有授权或 8051 课程指定时使用；最终时序、噪声、死区和保护必须由实物与仪器验证。
- **软件层：**先理解 [CMSIS-Core](https://arm-software.github.io/CMSIS_6/latest/General/index.html)，自己实现并验证移动平均、IIR 或 PI 后再用 [CMSIS-DSP](https://arm-software.github.io/CMSIS-DSP/latest/index.html)优化。完成中断、DMA 和非阻塞状态机后才加入 [FreeRTOS](https://www.freertos.org/Documentation/02-Kernel/01-About-the-FreeRTOS-kernel/01-FreeRTOS-kernel)；快速采样和控制环仍由定时器/ADC 硬件触发，通信、日志和 UI 才放任务中。
- **电机控制进阶：**确定近期要做三相电机时，可用 [P-NUCLEO-IHM03](https://www.st.com/en/evaluation-tools/p-nucleo-ihm03.html)代替单买 G474RE。套件含 NUCLEO-G431RB、低压三相驱动板、电机和电源，并配 [STM32 Motor Control SDK](https://www.st.com/en/embedded-software/x-cube-mcsdk.html)；先理解互补 PWM、死区、ADC 同步、电流采样、六步换相和保护，再把 Workbench/FOC 当作实现对照。

建议项目按以下顺序递进：

1. GPIO LED/按键、外部中断消抖、UART 命令行和有限状态机。
2. 定时器周期任务、PWM、输入捕获/正交编码器、I²C 传感器和 SPI 外设，并实测总线与时序。
3. 定时器触发 ADC + DMA 环形缓冲，串口输出数据，实现滤波并量化采样抖动、CPU 占用和延迟。
4. 现成 H 桥 + 带编码器低压直流电机：速度 PI/PID、斜坡、饱和与 anti-windup、堵转/过流/急停状态；严禁 MCU 引脚直接驱动电机。
5. 学完自动控制、电机学和电力电子后，再做 BLDC/PMSM 六步或 FOC。

## 推荐学习路线

组合为：**Dean 第二版主教材 + Quantum Leaps 配套课 + 张毅刚/HIT 查漏 + NUCLEO-G474RE 实验**，再用 **Mastering STM32、ST MOOCs、Cornell 项目和官方电机套件**完成工程化与控制系统进阶。

1. **补齐前置。**定向复习 C 的指针、位运算、`volatile`、多文件、结构体和有限状态机；复习数电时序、晶体管/MOSFET 接口、运放与 ADC 基础。**通过标准：**能读简单原理图和 datasheet 引脚表，独立编译、下载、单步并解释一段寄存器操作代码。
2. **建立 Cortex-M 与并发模型。**精读 Dean 第 1—5 章，并跟做 Quantum Leaps 的 C、机器执行、GPIO、中断与启动相关课程；在 G474RE 上完成按键、LED、UART 和非阻塞状态机。汇编只需看懂启动、栈和函数调用，不做大规模汇编练习。**通过标准：**能解释轮询与中断的取舍、NVIC 优先级和 ISR 约束，程序无长时间阻塞 `delay`，并能用调试器定位一次异常。
3. **打通确定性数据通路。**学习 Dean 第 6—9 章，并用 Mastering STM32 查定时器、ADC/DAC、DMA、UART、I²C、SPI、PWM、输入捕获和编码器；同时复习采样、混叠、量化和数字滤波。**通过标准：**完成“定时器触发 ADC → DMA 环形缓冲 → 滤波/处理 → 串口或 PWM 输出”，实测采样周期与抖动，且主循环不靠轮询维持采样。
4. **并行完成校内考核。**按任课教师 syllabus 用张毅刚教材和 HIT MOOC 补 8051 内存结构、寻址/指令、汇编、中断、定时器、串口和接口扩展；考试不要求的历史性扩展略读。**通过标准：**能完成传统计算与程序题，并能说明同一功能在 8051 与 Cortex-M 上的实现差异。
5. **工程化软件。**把驱动、服务和应用分层，加入超时、错误恢复、Fault 记录、事件状态机与可测试的纯算法模块；用 CMSIS-DSP 前先保留自己的基准实现。只有单主循环/中断版本稳定后再学习 FreeRTOS 的 task、queue、semaphore 和优先级反转。**通过标准：**能给出 ISR/任务分工、最坏响应时间和故障路径，新增通信或日志不会破坏采样控制周期。
6. **完成第一套闭环对象。**用低压直流电机、H 桥、编码器和必要的电流/电压检测，实现固定周期速度环，再加入限幅、anti-windup、软启动、堵转和急停。把自动控制中的采样周期、带宽、稳定性与实际 PWM/传感器误差对应起来。**通过标准：**提交设定阶跃和负载扰动曲线，能解释超调、稳态误差、控制周期、占空比限幅及每个保护状态。
7. **进入三相电机与专用控制器。**学过自动控制原理、电机学和电力电子后，选做 Cornell 控制项目或 P-NUCLEO-IHM03：先六步换相，再理解电流采样、Clarke/Park、PI 电流环、SVPWM 与 FOC。完成 STM32 主线后，若继续电机/数字电源方向，再转 [TI C2000 MotorControl SDK](https://www.ti.com/tool/C2000WARE-MOTORCONTROL-SDK)，不与入门阶段并学。**通过标准：**能解释“采样—坐标变换—电流环—PWM—功率级—保护”的完整数据与能量链，而不只是让生成代码把电机转起来。
