## 📖 关于本库

- **组织方式**：按学科分目录，每个知识点尽量拆成独立的原子笔记，通过双向链接（`[[...]]`）串联成网。
- **重点学科**：数学部分（微积分 + 线性代数）积累最完整，共 145+ 篇，是本库的核心。
- **同步**：使用 Obsidian + Git 备份，`.obsidian/workspace` 等本地布局文件已通过 `.gitignore` 排除。

## 🛠️ 如何使用

```bash
git clone https://github.com/w23x0/obsidian.git
```

用 Obsidian 打开克隆下来的文件夹作为 Vault，即可获得完整的双向链接与关系图谱体验。直接在 GitHub 上浏览也可以，点上面目录里的链接即可跳转。
