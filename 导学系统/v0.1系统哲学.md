AI主导的个人自学进化系统

五层
1. 资料层
原始知识来源：教材、笔记、题目、网页、视频、论文。

2. 知识网络层
把资料转成可学习、可连接、可上升的知识结构。

3. 学习者模型层
记录“我现在在哪里”：掌握、误区、能力层次、现实状态。

4. 教学策略层
AI 决定下一步怎么学、怎么问、怎么评估、怎么引导。

5. 闭环层
学习后反向更新资料、网络、学习者模型、策略。

每一层内部都有：
底层事实/节点
中层结构/方法
高层模型/思维
跨塔连接/迁移

AI 主导动态演化，结构负责沉淀结果

静态资料不重要，动态结构重要
固定算法不重要，演化证据重要
AI 可以改，但要留下为什么改

基础网络：由 RAG/AI 从资料中抽取
学习网络：由你的学习过程逐渐修改
高层网络：由反馈、类比、总结、迁移慢慢生成

资料生成基础节点
学习生成真实连接
反馈生成高层思维网络

提示词可以负责判断，但底层还是要有几个稳定维度。比如先定
知道：见过这个概念
理解：能解释它是什么意思
操作：能做基础题
推导：知道它从哪里来
辨析：能区分相近概念
迁移：能用到新场景
综合：能把多个知识组织成模型
**闭环可以这样理解**
正
资料 -> 基础知识网络 -> 学习决策 -> 学习过程 -> 反馈
反
反馈 -> 修改笔记
反馈 -> 修改知识网络
反馈 -> 修改学习者模型
反馈 -> 修改后续教学策略
向上
基础知识 -> 方法知识 -> 模型知识 -> 思维知识 -> 综合迁移
循环的目的是向上学习


所以这个系统最核心的功能不是“问答”，而是：
方向保持 深度控制 多线程学习管理 阶段复盘 全局结构感 高维总结
即 学习导航层
