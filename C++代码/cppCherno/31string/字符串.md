字符串的本质：在 C++ 中，字符串本质上是字符数组（Arrays of characters）
字符编码与大小：标准 char 类型占用 1 字节 内存。视频提到，由于 1 字节只能表示 256 种，
对于中文或日文等复杂语言，
通常需要使用 std::wstring 或 UTF-8 等更宽的字符编码

C 风格字符串（C-Style Strings）：

定义方式为 const char* name = "Cherno";
内存逻辑与空终止符（Null Termination）：C 风格字符串以一个值为 0 的字节（即空终止符 \0）结尾 
底层原理：当程序读取字符串时，它会从起始内存地址开始，一直读取到遇见 0 为止。
如果手动创建字符数组但漏掉了 0，程序会继续读取相邻的内存区域，导致输出**乱码** 

C++ 标准库字符串 (std::string)：

它是 <string> 头文件中的一个类，底层依然是字符数组
字符串拼接：直接用 + 接两个字符串字面量（如 "a" + "b"）会报错，因为它们是 const char* 指针，不能相加
需要确保其中至少一个是 std::string 类型 

#include <string>

std::string str = "Hello";
str += " World";           // 拼接
str.size();                // 长度（不含 \0）
str.find("World");         // 查找，返回位置索引


std::string s = "Hello";
const char* c = s.c_str();   // std::string → C风格字符串

性能优化：传递字符串：

在函数中传递字符串时，应避免直接使用 std::string（这会触发内存分配和对象拷贝，性能较低）

推荐做法：使用 常量引用 (const std::string&) 进行传递，
这样既能避免拷贝，又能确保函数不会修改原始字符串

使用双引号直接定义一串纯文本，它在底层本质上就是一个常量字符数组,天生带有 const.只读的内存
