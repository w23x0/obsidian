继承 (Inheritance)，
它是面向对象编程（OOP）的核心概念，
主要用于减少代码重复并建立类之间的层次结构

基本语法
class Player : public Entity  // Player 继承了 Entity
使用冒号 : 后跟访问修饰符（如 public）和基类名称来定义继承关系0‘

内存表现：派生类会包含基类所有的成员变量。

多态（Polymorphism）：
如果 Player 继承自 Entity
内存开头部分是一模一样的
父类指针可以指向子类对象
子类对象在内存里的排列顺序是：先放父类的成员，再放子类自己的成员

指针本质上就是一个内存地址。
Entity* ptr 告诉编译器：“从这个地址开始看，前 8 个字节是我的数据。”
Player* ptr 告诉编译器：“从这个地址开始看，前 12 个字节是我的数据。”

让你能用一个通用的身份去操作一群不同的对象



访问权限：派生类可以访问基类中除了 private 以外的所有成员
扩展性：派生类可以在基类的基础上添加新属性、新方法，或者修改（Override）基类的行为

内存逻辑：子类对象在内存中完整包含父类的所有成员类型转换
类型转换：由于内存布局的向下兼容性，父类指针可以存储子类对象的地址
权限限制：虚函数作用地方

如果没有虚函数的重写
继承相同函数是隐藏
但是编译器就近原则
内存中子类访问对象优先看到自己的函数
父类访问只能看到父类的函数，所以才引入的虚函数表（vtable）机制来实现多态
