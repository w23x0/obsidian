## 教材

### 主教材

**陈珩《电力系统稳态分析》第四版，中国电力出版社，2015**

全书六章，依次覆盖基本概念、元件与网络模型、简单网络潮流、复杂系统潮流算法、有功—频率调整、无功—电压调整；范围与国内本科课程、期末和后续供配电/故障分析的接口最一致。难度中等，前置是相量与三相电路、变压器和同步发电机稳态模型、节点法及基础矩阵运算。对当前路线而言，它比一本覆盖暂态、保护和市场的厚教材更高效，适合作为章节主线和国内术语/题型依据。

本书在牛顿—拉夫逊法、PQ 分解法、稀疏技术、状态估计与最优潮流之间安排紧凑，自学时有些推导会显得跳跃；遇到网络方程和潮流算法不应反复硬啃，转用下列 Grainger 教材和 NPTEL 课程补解释。

### 理论辅助教材

**John J. Grainger, William D. Stevenson, Gary W. Chang, _Power System Analysis_, SI Edition, McGraw-Hill, 2016**

面向高年级本科/研一，体系完整、例题和章末题较多。第 2—7 章把三相功率、变压器与同步机、线路参数、网络矩阵和多种潮流算法连成一条清楚的推导链；第 12 章补经济调度与自动发电控制。难度略高于陈珩，适合在“为什么这样建模、公式从何而来”处定点查阅，不必顺序读完。

推荐 SI 版而不是直接找 1994 年旧版：该版使用 SI 制、增加现代电网背景，并附大部分例题的 MATLAB 程序。其 GUIDE 图形界面和 R2013a 工具链已经偏旧，代码只用于核对思路，实际仿真改用 MATPOWER。

### 工程与仿真辅助教材

**J. Duncan Glover, Mulukutla S. Sarma, Thomas Overbye, Adam Birchfield, _Power System Analysis and Design_, 7th ed., Cengage, 2023**

内容从变压器、线路与潮流延伸到经济运行、故障、保护、稳定、控制和配电，并把 PowerWorld 仿真嵌入例题，工程场景和运行视角强。先修要求与主教材相同，数学推导不作为主要优势。只选读第 3—7、13 章，并配合 Texas A&M 的实验；它的作用是把手算模型变成“改负荷、发电、变比、并联补偿后观察电压、潮流与损耗”的操作经验，不需要与主教材逐章并读。

### 进阶选读

**Steven H. Low, _Power System Analysis: Analytical Tools and Structural Properties_，Caltech 开放讲义（19 章）**

分为电力网络模型/运行/分析、潮流优化、不平衡三相网络三部分，用线性代数、图论和优化揭示结构性质。它与控制算法路线的连接最好，但需要较强的矩阵分析和优化基础；完成普通潮流计算后再选读 Part I，只有准备深入最优潮流、分布式优化或电网控制研究时才进入 Part II/III。

## 免费网络课程

- [NPTEL: Power System Analysis](https://nptel.ac.in/courses/117105140)（Prof. Debapriya Das, IIT Kharagpur）：12 周、4 学分的完整本科课程，共 60 讲视频。前 8 周覆盖系统结构、线路参数、标幺制、元件模型、线路运行、潮流和经济运行，最适合配合主教材；后 4 周的故障、对称分量和稳定可作为后续继电保护/暂态分析入口。
- [NPTEL: Computer Aided Power System Analysis](https://nptel.ac.in/courses/108107127)（Prof. Biswarup Das, IIT Roorkee）：完整 60 讲，细讲 Ybus、Gauss–Seidel、极坐标/直角坐标 Newton–Raphson、快速解耦、AC/DC 潮流、稀疏消元、事故灵敏度、状态估计和故障计算。适合学完主线后按题目查讲，不适合零基础从第 1 讲一路代替主教材。
- [Texas A&M ECEN 460: Power Systems Operations & Control, Spring 2025](https://overbye.engr.tamu.edu/course-2/ecen460sp25/)（Prof. Thomas Overbye）：官方页面公开 26 份讲义/PPT、9 个实验、作业、带答案试卷和设计项目；从潮流、事故分析、经济调度到电压/稳定与新能源，工程完整度很高。没有公开课堂录像，实验原件使用 PowerWorld；没有完整教育版许可时，阅读任务书并在 MATPOWER 小算例上复现其控制变量和评价指标。
- [Caltech Power System Analysis 开放教材与讲义](https://netlab.caltech.edu/book_reg/)（Steven H. Low）：注册后可下载 19 章草稿和配套 slides。它是完成本科主线后的算法型专题资源，不用于备考或第一次学习潮流。

## 实践与仿真

- [MATPOWER](https://matpower.org/)：主实践工具。它是面向 MATLAB/免费 GNU Octave 的开源稳态仿真与优化包，支持 AC/DC 潮流、连续潮流和 OPF，代码与网络方程对应清楚。先只使用 `runpf`、`case9`、`case14` 和结果结构；不要一开始进入 OPF、机组组合或大规模算例。
- [PowerWorld Simulator Demo](https://www.powerworld.com/download-purchase/demo-software)：可选的 Windows 图形工具，免费教育/评估版限制为 13 个母线，但带单线图、潮流、OPF、PV/QV 等功能。适合建立“操作量—系统响应”的直觉并熟悉 Glover/Texas A&M 的界面；不是必需软件，也不应为本课专门购买完整版。
- [pandapower](https://pandapower.readthedocs.io/en/latest/)：仅当后续希望用 Python 做配电网、自动化或时序控制时再换用。它提供 AC/DC/不平衡三相潮流、事故分析、状态估计以及 controller/time-series 模块；本课程期间不要与 MATPOWER 并行学习两套接口。
- **最小闭环项目**：先自己写一个 3 母线 Newton–Raphson 潮流程序，并与 MATPOWER 结果核对；再在 `case9`/`case14` 中依次改变负荷、发电机有功、变压器变比和并联无功补偿，记录母线电压、支路潮流和网损；最后做一次 N−1 线路退出并给出调度/调压方案。输出应包含假设、标幺基准、关键结果表和工程解释，而不只是软件截图。

## 推荐学习路线

以“陈珩第四版 + NPTEL 主课程”为主线，用 Grainger 定点补推导、MATPOWER/Octave 验证计算，再用 Texas A&M 讲义和实验建立运行视角；Glover、PowerWorld、pandapower 和 Low 均为按需资源。

1. **补齐前置。** 定向复习复数相量、对称三相功率、节点电压法、理想/实际变压器、同步发电机稳态等值电路和 Newton 法。能独立完成三相功率换算、变比折算和一次 Newton 迭代后进入主线。
2. **建立统一模型。** 学陈珩第 1—2 章、NPTEL 第 1—4 周；Grainger 第 2—6 章只补不清楚的推导。重点是标幺制、发电机/变压器/线路/负荷模型、π 型等值和 Ybus。阶段标准是：给出单线图和基准值，能独立形成标幺等值网络与节点导纳矩阵，并说明每个近似的适用条件。
3. **攻克潮流计算。** 学陈珩第 3—4 章、Grainger 第 7 章、NPTEL 第 5—6 周；手算一个简单辐射/环网，再实现 3 母线 Newton–Raphson，并用 MATPOWER 的 `case9`/`case14` 校验。必须能解释平衡（slack）/PV/PQ 母线、功率失配、Jacobian、收敛判据及快速解耦近似，而不是只会调用 `runpf`。
4. **完成稳态运行与调节。** 学陈珩第 5—6 章，Grainger 第 12 章补经济调度和 AGC；NPTEL 第 7—8 周补最优运行。抓住有功—频率、无功—电压的主耦合关系，以及调速器、励磁、变压器分接头、并联电容/电抗器各自能改变什么。能针对越限结果选择控制量并预测变化方向，才算掌握本课最值得迁移到自动控制路线的部分。
5. **做一次工程化验证。** 选读 Texas A&M ECEN 460 第 3—15 讲，并参考 Lab 2、4、5 的任务设计，在小算例上完成负荷增长、发电重调度、变比/补偿调压和一次 N−1 分析。阶段产物是一份短报告：模型与基准、修改前后潮流、电压和损耗、约束、控制方案及原因。
6. **收尾并分流。** 完成标准是能对 5—14 母线系统走通“建模 → 求解 → 校核 → 解释 → 调整”，并说清 P–f、Q–V 与 N−1 的意义。之后进入供配电/发电厂电气部分；为继电保护补 Grainger 第 8—10 章或 NPTEL 第 9—11 周。只有对数值算法或电网控制产生明确兴趣时，再学 Computer Aided Power System Analysis 的稀疏计算/状态估计部分和 Low 的 Part I/II；电力市场、研究级 OPF 和大规模合成电网不是当前必修。
