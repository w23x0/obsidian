## 教材

### 主教材

**Gilbert Strang, [*Introduction to Linear Algebra*, 6th ed.](https://math.mit.edu/~gs/linearalgebra/ila6/indexila6.html)（Wellesley-Cambridge Press, 2023）**

从列空间、线性组合和矩阵分解组织内容，直观但不牺牲计算。第 1—7 章覆盖四个基本子空间、消元与 LU、投影与最小二乘、QR、特征值、对称正定矩阵、复矩阵、线性微分方程与 SVD；第 8 章讲线性变换，第 9—10 章偏优化和数据学习。只需基本代数即可开始，矩阵指数部分需要微分方程基础。它同时覆盖控制所需的模态、`exp(At)`、投影和 SVD，最适合作为定向复习的主线；行列式技巧和后两章不必等量投入。

### 国内课程与考试辅助

**同济大学数学科学学院《[工程数学 线性代数（第七版）](https://www.hep.com.cn/book/show/ea81ec46-0250-40bc-846c-9b9f5f3f62ae)》（高等教育出版社，2023）**

篇幅短，按国内工科课程顺序覆盖行列式、矩阵与方程组、向量组与秩、特征值、二次型、线性空间与线性变换，适合查术语、补课堂范围和应对校内考试。它不系统讲投影与最小二乘、QR、SVD、条件数和矩阵指数，因此只作查漏与题型训练，不承担工程主线。

### 工程应用辅助

**Stephen Boyd、Lieven Vandenberghe, [*Introduction to Applied Linear Algebra: Vectors, Matrices, and Least Squares*](https://vmls-book.stanford.edu/)（Cambridge University Press, 2018）**

官方免费电子版，并配有讲义、视频及 Julia/Python 伴随材料；几乎不要求先修线性代数，少量微积分也不是硬前置。全书用 QR 和最小二乘贯穿卷积、线性动力系统、数据拟合、控制与状态估计，适合把手算概念转成可运行模型。它有意不讲特征值和 SVD，不能替代 Strang；已有基础时应选读第 7、9—13、15、17 章，而非从头逐页重学。

### 进阶教材（按需）

**Lloyd N. Trefethen、David Bau III, [*Numerical Linear Algebra*, Twenty-fifth Anniversary ed.](https://epubs.siam.org/doi/book/10.1137/1.9781611977165)（SIAM, 2022）**

面向已掌握基础线性代数、微积分并能编程的读者，以 40 讲讨论 QR、最小二乘、条件数与稳定性、特征值/SVD 算法及迭代法。它的作用不是加深符号推导，而是解释同一个数学问题为何会因算法和浮点误差得到不同结果；只有在做系统辨识、估计器、较大稀疏模型或嵌入式数值实现时再进入。

## 免费网络课程

- [MIT OCW 18.06SC Linear Algebra](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/)：Gilbert Strang 主讲，按三个单元覆盖四个基本子空间、最小二乘、特征值、`exp(At)`、正定矩阵、SVD 和伪逆。含完整视频、讲义、习题与解答、解题视频、三次单元考试及期末考试，最适合与主教材同步自学。
- [3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra)：用动画解释张成、基、线性变换、行列式、特征向量和换基。适合在读对应章节前建立几何图像，但没有足量习题，不能代替教材或 MIT 课程。
- [Stanford SEE EE263 — Introduction to Linear Dynamical Systems](https://see.stanford.edu/Course/EE263)：Stephen Boyd 的电气工程课程，20 讲视频配完整讲义、作业、考试与解答及 MATLAB 数据；内容从 QR、最小二乘和 SVD 延伸到矩阵指数、稳定性、MIMO、可控性、可观性和状态估计。应在线性代数核心完成，并具备微分方程、Laplace 变换和传递函数基础后学习，是通往信号与控制的首选进阶课。
- [MIT OCW 18.065 — Matrix Methods in Data Analysis, Signal Processing, and Machine Learning](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/)：含视频、阅读材料、习题和期末项目；前半段集中于低秩近似、范数、最小二乘以及特征值/SVD 的计算，后段含 Fourier 矩阵、循环矩阵与卷积。信号或数据方向可选学，控制主线不必跟完深度学习部分。

## 实践与仿真

- **MATLAB/Simulink 主选，GNU Octave 兜底**：有学校授权时使用 [MATLAB Linear Algebra](https://www.mathworks.com/help/matlab/linear-algebra.html) 的 `A\b`、`qr`、`svd`、`eig`、`expm`、`cond`；没有授权可用免费的 [GNU Octave](https://docs.octave.org/latest/Linear-Algebra.html) 完成基础矩阵实验。不要把显式求逆 `inv(A)*b` 当作默认解方程方法。
- **全免费 Python 路线**：用 [NumPy `linalg`](https://numpy.org/doc/stable/reference/routines.linalg.html) 做分解与求解，[SciPy `linalg`](https://docs.scipy.org/doc/scipy/reference/linalg.html) 做矩阵指数及 Lyapunov/Riccati 方程，随后用 [Python Control Systems Library](https://python-control.readthedocs.io/en/stable/) 做状态空间分析和仿真。它与 Boyd 书的 Python 伴随材料衔接自然；与 MATLAB 二选一作为本课程主环境即可。
- **数值可靠性小实验**：对病态矩阵和带噪超定方程，比较显式求逆、直接求解、正规方程、QR 与 SVD 的残差、参数误差和条件数；再改变噪声与采样数量。目标是理解“残差小”不等于“参数可靠”，并形成先看尺度、秩和条件数的习惯。
- **直流电机状态空间项目**：以 University of Michigan CTMS 的 [DC Motor Speed: System Modeling](https://ctms.engin.umich.edu/CTMS/index.php?example=MotorSpeed&section=SystemModeling) 为对象，建立 `A,B,C,D`，计算模态、`exp(At)`、离散更新、可控/可观秩并对比时域仿真；再用带噪电流和转速数据做一次最小二乘参数辨识。先完成模型和数值检查，不在本课程阶段扩展到控制器整定。
- **电机坐标变换小项目（可选）**：参考 MathWorks 的 [Clarke and Park Transforms](https://www.mathworks.com/discovery/clarke-and-park-transforms.html)，自己构造 `abc → αβ0 → dq0` 的变换矩阵，明确采用幅值不变还是功率不变归一化，验证逆变换、功率关系，并观察平衡三相正弦量在同步旋转坐标系中变成近似直流量。这是换基、正交性与后续磁场定向控制的直接连接。

## 推荐学习路线

采用“Strang 第六版 + MIT 18.06SC 为核心，同济第七版查漏，Boyd/Vandenberghe 做工程计算，MATLAB 或 Python 完成项目，最后按控制需求进入 EE263”的组合。

1. **先诊断，不从零重学。** 限时完成 MIT 18.06SC 的 Exam 1—3 中各一组代表题；不会的内容再查同济教材。优先确认消元、秩、基与维数、特征值和二次型，行列式展开与克拉默法则只需达到国内课程要求。能独立判断方程组解的结构、求子空间基并解释秩的含义后进入主线。
2. **重建工程所需核心。** 按 Strang 第 1—4、6—7 章配 MIT 三个单元学习，第 5 章快速复习，第 8 章选读换基与线性变换；第 9—10 章暂列可选。重点是四个基本子空间、投影/最小二乘、QR、特征分解、对称正定矩阵、复特征模态、`exp(At)`、SVD 与伪逆。3Blue1Brown 只在相应主题前后辅助直觉。进入下一阶段前，应能从几何、代数和计算三种角度解释上述概念，并完成一套期末卷。
3. **把概念变成稳定计算。** 在 MATLAB/Octave 或 Python 中重做消元、QR、最小二乘、特征分解、SVD 和矩阵指数，完成数值可靠性实验；同步选读 Boyd 第 7、9—13、15、17 章。达标标准是脚本可复现、会报告残差与条件数、知道何时用 QR/SVD 而不是正规方程或显式求逆，并能用带噪数据完成一次参数拟合。
4. **连接信号与自动控制。** 学过常微分方程、Laplace 变换和传递函数后进入 EE263，重点学习模态的动态解释、矩阵指数、连续/离散状态空间、可控性、可观性和最小二乘状态估计，并完成直流电机项目。给定一个实际 `A,B,C,D` 模型，能判断稳定性和可控/可观性、写出状态转移、正确离散化并解释仿真结果，才算完成线性代数到控制的桥接。
5. **按后续任务分支，不做无目的进阶。** 电机控制方向完成 Clarke/Park 项目；信号与数据方向选学 MIT 18.065 的低秩、SVD、Fourier/循环矩阵与卷积部分；需要实现大型或高可靠数值算法时再读 Trefethen 与 Bau。Jordan 标准形的繁复手算、行列式恒等式和纯抽象证明不是当前主线，除非后续课程或研究明确要求。
