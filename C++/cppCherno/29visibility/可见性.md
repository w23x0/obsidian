

可见性规定了谁可以“看到”并调用类的特定成员。它**纯粹是编程语言层面的约束**，
用于组织代码和提高可维护性，对程序运行性能或 CPU 执行没有任何影响 [00:34]。

三大修饰符：
**private (私有)**
只有该类本身（以及 friend 友元类/函数）可以访问。
在 class 中，未指定修饰符的成员默认为 private
**protected (受保护)**
该类及其所有子类（继承体系内）可以访问，但类外部无法访问 
**public (公有)**
任何地方都可以访问。在 struct 中，
未指定修饰符的成员默认为 public 

为什么要使用可见性？
**API 设计与安全性**：通过将变量设为 private 并提供 public 的 Setter/Getter 方法，
可以确保在修改数据时触发必要的逻辑（例如刷新 UI 或验证数据），防止外部代码直接破坏对象状态 。
**代码维护**：明确告诉其他开发者（或未来的自己）哪些部分是内部实现细节，
不应该被直接改动。这降低了系统各部分之间的耦合度 。
**友元 (Friend)**：C++ 提供 friend 关键字，
允许特定的外部类或函数访问另一个类的 private 或 protected 成员 。


类和结构体区别
1. 默认访问权限
class 默认是 private 的，而 struct 默认是 public 的。
1. 这是 C++ 设计上的一个约定
2. 默认继承方式
在定义派生类（子类）且未指定继承类型时：
1. struct：默认以 public 方式继承基类。
class：默认以 private 方式继承基类。
