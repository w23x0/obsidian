## 教材

### K. N. King, [*C Programming: A Modern Approach*](http://knking.com/books/c2/), 2nd ed.（2008）

主教材

完整覆盖 C89/C99，并清楚标出 C99 的变化；从表达式、类型、函数和数组逐步进入指针、字符串、预处理、多文件程序、结构体/联合/枚举、程序设计、位级操作和标准库。编排细、练习多，适合建立系统而不是只背语法；只要求具备基本程序设计经验。

已有 C++ 基础时，第 2—10 章用练习快速校准即可，主要投入第 11—20 章；第 21—27 章按项目需要查阅。它不覆盖 C11—C23 的新增内容和现代诊断工具，因此用下述 *Effective C* 与实际工具链补齐，而不是换用多本入门书重复学习。

### 何钦铭、颜晖《C语言程序设计（第4版）》（高等教育出版社，2020，ISBN 978-7-04-054506-7）

国内课程与考试辅助教材

按国内工科课程常见顺序组织控制结构、数组与函数、指针与字符串、结构类型、链表和文件，前置要求低，配套练习便于做限时训练。它的作用是统一中文术语、输入输出细节和本校笔试/机试题型；对已学过 C++ 的学生不必从头通读，也不应替代主教材中的内存模型、多文件设计和工程项目。

### Elecia White, [*Making Embedded Systems: Design Patterns for Great Software*](https://www.oreilly.com/library/view/making-embedded-systems/9781098151539/), 2nd ed.（O'Reilly, 2024）

工程应用教材

这不是 C 语法书，而是从“能写 C”到“能组织固件”的桥梁，重点是硬件/软件边界、状态机、事件与中断、并发、时序、内存约束、调试、测试和固件架构。完成指针、多文件和基本数字电路后再读，配合单片机课程使用；它直接服务于以后把采样、控制算法、通信和执行接口组成可靠控制器。

### Robert C. Seacord, [*Effective C*](https://nostarch.com/effective-c-2nd-edition), 2nd ed.（No Starch Press, 2024）

进阶教材

第二版按 C23 重写，覆盖对象、函数与类型，整数与表达式，动态内存，字符与字符串，I/O、预处理、多文件结构以及调试、测试和分析。完成至少一个多文件项目后选读，用来补齐整数提升与溢出、对象生存期、别名、未定义行为、分配失败和错误处理等容易从 C++ 经验中误判的问题。

嵌入式编译器通常只完整支持 C11/C17 或其子集，因此重点吸收语义规则和安全写法；C23 专属语法按工具链支持情况选学，不为追新而引入不可移植代码。

## 免费网络课程

- [MIT OCW 6.087 — Practical Programming in C](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/)：最适合作为配套主课。它假定已经学过一门程序设计课程、不要求 C 基础，以三周高强度方式从语法进入动态内存、库、多进程信号、并发与同步；官方页面保留完整 syllabus、讲义、日常作业、实验和项目，但没有整套课堂视频。对本路线而言，先完整做 C 与内存部分，UNIX 进程和线程部分按兴趣选做。
- 浙江大学翁恺的[《程序设计入门——C语言》](https://www.icourse163.org/course/ZJU-199001)与[《C语言程序设计进阶》](https://www.icourse163.org/course/ZJU-200001)：两段课程合起来覆盖控制结构、数组、函数、指针、字符串、结构/联合、链表、预处理、多文件结构、函数指针和文件，视频与编程练习较完整。已有 C++ 基础时先做测验定位，只补薄弱周；它主要配合国内教材和课程考核，不与 MIT 课程双线从头学习。
- [Beej's Guide to C Programming](https://beej.us/guide/bgc/)：免费、完整的在线教材，适合在主教材讲解不够直观时换一个角度阅读，也可用于快速查找编译、指针、预处理、I/O、未定义行为、线程和原子操作等专题。它是查阅和补充资料，不替代主线练习。

## 实践与仿真

- **主机端工具链**：用 GCC 为主、Clang 复核，先固定 `-std=c17 -Wall -Wextra -Wpedantic`，理解整数转换后再加 `-Wconversion`；见 [GCC Warning Options](https://gcc.gnu.org/onlinedocs/gcc/Warning-Options.html)。指针和动态内存阶段使用 [GDB](https://sourceware.org/gdb/current/onlinedocs/gdb.html) 练断点、观察点、调用栈和内存，并开启 [AddressSanitizer](https://clang.llvm.org/docs/AddressSanitizer.html) 与 [UndefinedBehaviorSanitizer](https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html)。Sanitizer 用于主机测试，不是裸机 MCU 调试方案。
- **定向题库**：[Exercism C Track](https://exercism.org/tracks/c) 提供免费自动测试和代码分析。优先做字符串/内存、`binary-search`、`robot-simulator`、`circular-buffer`、`linked-list` 等题，不必刷满；国内教材配套题只用于限时考试训练。
- **单元测试**：[Unity](https://www.throwtheswitch.org/unity) 是小型纯 C 测试框架，适合测试环形缓冲、协议解析、状态机、数字滤波和 PID；Mock 与测试工程明显变复杂后再引入 [Ceedling](https://www.throwtheswitch.org/ceedling)。先把硬件访问隔离在接口后，算法模块才能在 PC 上反复验证。
- **MCU 仿真与真机**：[Wokwi](https://docs.wokwi.com/) 可在官方支持的板卡上验证 GPIO、定时、UART、I²C、SPI 和状态机，并用逻辑分析仪检查数字时序；它不能代替功率驱动、电机本体或闭环机械系统仿真。完成主机端项目后再用 [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) 配合 STM32/Nucleo 真机，练习编译、下载、断点、寄存器/内存观察以及 ADC、定时器、DMA、PWM。
- **进阶项目库**：[Cornell ECE 4760/5730](https://ece4760.github.io/) 的 RP2040/RP2350 资料包含定点数、数字滤波、SPI/I²C/UART、DMA、PID 和开放项目。它适合在 C 与单片机基础完成后选题，不是 C 入门实验课。
- **建议项目链**：位掩码与“寄存器”模拟器 → 多文件环形缓冲、按键消抖状态机、CRC 与 UART 帧解析 → 读取/输出 CSV 的移动平均、IIR、限幅和离散 PID → Wokwi 上的“周期采样—滤波/控制—PWM—串口命令” → STM32 真机。多文件阶段先亲手完成一次编译与链接，再学习最小构建配置；不要把学习重心放在 IDE 设置上。

## 推荐学习路线

以 King 第 2 版和 MIT 6.087 为主线，何钦铭教材与翁恺课程补国内考核，*Effective C* 和 *Making Embedded Systems* 分别补安全语义与固件设计，再用“主机测试 → MCU 仿真 → 真机外设”的项目链完成闭环。

1. **快速完成 C/C++ 语义换挡。** 快读 King 第 2—10 章并完成 MIT 前半段作业，重点比较声明与类型转换、数组退化、以 `\0` 结尾的字符串、值传递、作用域和标准输入输出；不要把 C 写成“没有类的 C++”。达标标准：所有小程序能以 C17 模式零警告编译，并能解释数组长度为何不能从形参指针中恢复。
2. **攻克内存与底层核心。** 精读 King 第 11—20 章，完成 MIT 的指针、结构体和动态内存实验；掌握指针算术、对象生存期、栈/静态存储期/堆、字符串边界、结构体/联合/枚举、函数指针、头文件、内部/外部链接、宏和位运算。动态分配必须会用，但长期运行的裸机程序只有在边界和失败策略明确时才使用。达标标准：能独立实现多文件环形缓冲或帧解析器，并在警告、ASan 和 UBSan 下通过测试。
3. **并行补齐国内课程要求。** 用何钦铭第 4 版目录和翁恺两段课程做诊断，只补 `scanf`/`printf` 格式、循环与数组题、指针/字符串、链表、文件和代码阅读等薄弱项。达标标准：在限定时间内完成一题同时使用函数、数组或指针、结构体和文件的综合题，并能手算关键变量与内存变化。
4. **建立可测试的工程结构。** 依次完成按键消抖状态机、CRC/UART 解析和环形缓冲，把 `.h` 接口、`.c` 实现、硬件适配层与测试分开；用 Unity 覆盖正常路径、边界、超时和错误输入，并用 GCC、Clang 各编译一次。同步选读 *Effective C* 的整数、内存、字符串、程序结构和工具章节。达标标准：更换模拟硬件接口不需要修改算法模块，测试中不存在越界、泄漏、未初始化读取和依赖求值顺序的表达式。
5. **连接信号与控制算法。** 在 PC 上先实现浮点移动平均/IIR、限幅和离散 PID，用固定测试向量或 CSV 对照结果；随后选做定点量化、饱和运算和溢出分析。采样周期必须作为明确参数，算法中不直接读写寄存器。达标标准：边界、阶跃和异常输入都有可重复测试，数值范围与误差可以说明，而不只是“曲线看起来正常”。
6. **迁移到控制器。** 先在 Wokwi 验证周期调度、GPIO/定时器、通信和 PWM 数字时序，再迁移到 STM32/Nucleo；配合 *Making Embedded Systems* 学习状态机、中断、并发、看门狗、错误恢复和调试。`volatile` 只解决特定可见性/访问问题，不能替代原子操作、临界区或同步；中断服务应短小，控制算法留在可测试模块中。达标标准：能测出采样周期与最坏执行时间，通信异常不会卡死主循环，关键共享数据有明确的并发策略。
7. **在后续课程中完成系统闭环。** 本课程到“可靠地产生采样、控制量和 PWM/通信输出”即可；功率器件、电流/电压采样、保护、电机模型和机械负载分别留给模电、电力电子、电机学、信号与系统和自动控制原理。最终项目再把控制器、离散算法、功率驱动和电机连成完整系统，避免用 MCU 仿真器冒充功率与机电仿真。
